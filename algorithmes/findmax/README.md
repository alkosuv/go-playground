# Поиск наимбольшего значения

Задача найти наибольшее число в массиве.

Реализовано два метода в файле [findmax.go](algorithmes/findmax/findmax.go):
- FindMax – алгоритм работает за O(N)
- FindMaxSlow – алгоритм работает за (N^2)

## Таблица сравнений

|---|---|---|---|---|
| 10 | 6.71 нс | 11.20 нс | ~1.6 раза | 0 B/op (0 allocs) |
| 100 | 44.34 нс | 232.50 нс | ~5.2 раза | 0 B/op (0 allocs) |
| 1 000 | 410.80 нс | 3 099.00 нс | ~7.5 раза | 0 B/op (0 allocs) |
| 100 000 | 35 117.00 нс (35 мкс) | 560 120.00 нс (560 мкс) | ~16 раз | 0 B/op (0 allocs) |
| 1 000 000 | 351 031.00 нс (0.35 мс) | 5 872 738.00 нс (5.87 мс) | ~17 раз | 0 B/op (0 allocs) |
